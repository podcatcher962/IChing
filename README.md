## 中文

| 🎲 **自动摇卦** | 一键自动连摇六次，完整还原仪式感 |
| ⚡ **快速起卦** | 一键跳过动画，快速生成卦象 |
| 📜 **六十四卦** | 完整64卦数据，含卦辞、白话解读、爻辞 |
| 🔗 **变爻·之卦** | 本卦、变爻、之卦完整解读 |
| ✍️ **测字** | 输入一字或数字，拆解字象与卦象五行合参 |
| ⚔ **命盘合参** | 选填出生信息，八字日主与卦象五行联动解读 |
| 📅 **今日运势** | 根据卦象生成出行/财务/工作/休息/饮食/人际六维建议 |

| 🎴 **像素卦象卡** | Canvas 绘制卦象图 + PNG 下载 |

| 🌐 **中英双语** | 一键切换，所有内容全量翻译 |
| 🍀 **幸运参考** | 河图幸运数字、方位、卦象五行 |

## English

**IChing** is a single-file HTML I Ching divination tool. It visualizes the three-coin casting process, supports full bilingual Chinese/English interpretation, and integrates optional Bazi chart synthesis. Works offline, no data upload.

### ✨ Features

- Three-coin casting method (6 tosses, old yin/old yang auto-changing)
- Auto-cast: cast all 6 lines with one click
- Quick cast (skip animation)
- Complete 64 hexagrams with judgment texts, line texts, and interpretations
- Original hexagram + changing lines + transformed hexagram
- CeZi (character divination) with five-element analysis
- PixelBaZi chart synthesis (optional birth date input)
- Daily guidance: travel, finance, work, rest, diet, relationships
- History: auto-saves last 30 casts, click to revisit
- Pixel hexagram card (Canvas + PNG download)
- Copy reading + TXT report export
- Light & dark themes with saved preference
- Full bilingual Chinese/English toggle
- Lucky numbers and directions (He Tu)

### ⚠️ Disclaimer

Based on the I Ching (Book of Changes), **for cultural research and entertainment only**. Not scientific prediction. Do not use as basis for important decisions. All data stays in your browser's localStorage.
